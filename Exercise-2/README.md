# Exercise 2 – Deploy Flask App on Minikube

## Objective

Deploy a Flask application on a local Kubernetes cluster using Minikube, Docker, kubectl, and Kubernetes YAML.

## Files

- `app.py` – Flask application
- `Dockerfile` – Docker image configuration
- `flask-deployment.yaml` – Kubernetes Deployment and Service configuration
- `screenshots/` – Screenshots of the completed lab steps

## Technologies Used

- Python
- Flask
- Docker
- Kubernetes
- Minikube
- kubectl

## Result

The Flask application was successfully deployed on Minikube and accessed through a Kubernetes NodePort service.
